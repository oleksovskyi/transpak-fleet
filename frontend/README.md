# Frontend

`public/index.html` — робочий прототип інтерфейсу (статичний HTML + мок-дані),
відкривається прямо в браузері без збірки. Це референс вигляду й функціоналу,
не фінальна кодова база.

## Наступний крок
Попросіть Claude Code перенести структуру секцій, компоненти таблиць/карток і
логіку (перемикач періодів, розкривні рядки ТО, ролі admin/viewer) у обраний
фреймворк (React/Vue/Svelte), підключивши реальні дані через `/api/*` замість
мок-масивів у `<script>`.
