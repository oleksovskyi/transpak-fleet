# Frontend

React + Vite + TypeScript, підключений до реального `backend/` API (`/api/*`, проксується
через Vite dev server, див. `vite.config.ts`). Дизайн-система (палітра, картки, бейджі)
портована з `docs/transpak-dashboard-reference.html` — той файл лишається референсом
вигляду/логіки, не кодовою базою.

## Запуск
```
npm install
npm run dev
```
Бекенд (`cd ../backend && npm run dev`) має бути запущений на `:4000` — Vite проксує `/api`
на нього, тож CORS не потрібен.

## Стан підключення до реальних даних
- **Дашборд**, **Автопарк** — повністю на реальних `/api/trucks`.
- **ТО і ремонт**, **Водії**, **Маршрути**, **Паливо**, **Налаштування** — заглушки;
  підключення чекає на відповідні бекенд-ендпоінти (`/api/repairs`, `/api/drivers`,
  `/api/maintenance-types` тощо) і на дані від `sync-service` (пробіг/паливо/маршрути
  наразі порожні, бо Wialon ще не підключено).

## Наступні кроки
- Ендпоінти й екрани для ТО/ремонтів, водіїв, маршрутів, палива, налаштувань довідника ТО.
- Форма "Додати ТЗ" (backend `POST /api/trucks` вже є, форми на фронтенді ще нема).
- Графіки (пробіг у часі, маршрути, паливо) — після того, як `sync-service` почне наповнювати
  `MileageLog`/`FuelLog`/`RouteLog`.
